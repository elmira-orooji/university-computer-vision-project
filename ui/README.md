# پیکسل، آزمایشگاه تعاملی تصویر

از ریشهٔ پروژه اجرا کنید:

```powershell
python ui/server.py
```

سپس [رابط محلی](http://127.0.0.1:8766/) را باز کنید. تنها Python 3 لازم است؛ اجرای نسخهٔ ساخته‌شده به Node، Pillow یا OpenCV وابسته نیست. کد رابط با React، TypeScript و کامپوننت‌های رسمی Dig ساخته می‌شود و خروجی آماده در `ui/dist` قرار دارد.

امکانات رابط:

- بازکردن PNG از رایانه یا با کشیدن و رهاکردن فایل، همراه با دو تصویر نمونهٔ پروژه.
- نمایش تصویر و پنجرهٔ ۱۰ × ۱۰ ماتریس؛ انتخاب پیکسل با تصویر، مختصات عددی یا کلیدهای جهت‌نما در جدول رنگی.
- نمایش مقدار واقعی کانال‌های رنگ، شفافیت، رنگ نمایشی و نمای متنی ماتریس.
- بزرگ‌نمایی، حالت روشن و تیره با ذخیرهٔ تنظیم مرورگر، و چیدمان فارسی واکنش‌گرا.
- دریافت ماتریس کامل و PNG بازسازی‌شده، و تبدیل فایل متنی ماتریس به تصویر.

خواندن PNG از تابع اصلی پروژه استفاده می‌کند. پارامتر اختیاری `return_data` دسترسی رابط به ماتریس را فراهم می‌کند و رفتار معمول خط فرمان را تغییر نمی‌دهد. نوشتن PNG با روش سطرهای بدون فیلتر و تابع `write_png_chunk` پروژه انجام می‌شود. پوستهٔ وب پیش از رمزگشایی، امضای فایل، CRC، ابعاد و حجم دادهٔ بازشده را بررسی می‌کند.

حدود رابط: ۳ میلیون پیکسل، طول هر ضلع تا ۴۰۹۶، PNG تا ۱۲ میلیون بایت و ماتریس تا ۹۶ میلیون بایت. فایل متنی باید UTF-8 و با قالب خروجی پروژه باشد. ماتریس در حافظه نگهداری می‌شود؛ نتایج قدیمی با بازشدن فایل‌های جدید ممکن است حذف شوند و پس از راه‌اندازی مجدد باقی نمی‌مانند. دریافت فایل خروجی برای نگهداری نتیجه لازم است.

عمق ۱۶ بیت در تبدیل و فایل ماتریس حفظ می‌شود، حتی وقتی همهٔ مقدارها زیر ۲۵۶ باشند. رنگ نمایشی و HEX برای صفحه به ۸ بیت تبدیل می‌شوند. تصاویر پالتی و خاکستری کم‌عمق، برای خروجی قابل بازسازی به رنگ‌های مستقیم یا خاکستری ۸ بیت تبدیل می‌شوند. PNG بازسازی‌شده درهم‌تنیده نیست و اطلاعات جانبی مانند پروفایل رنگ را حفظ نمی‌کند. PNG متحرک پشتیبانی نمی‌شود.

درخواست مرورگر پس از ۹۰ ثانیه متوقف می‌شود؛ این توقف الزاماً پردازش جاری سرور را قطع نمی‌کند. سرور فقط روی loopback گوش می‌دهد و برای اجرای محلی طراحی شده است.

برای اجرای آزمون‌های تبدیل و API:

```powershell
python -m unittest discover -s ui/tests -v
npm --prefix ui/frontend ci
npm --prefix ui/frontend test
npm --prefix ui/frontend run build
```

آزمون‌ها از سرور موقت محلی و پوشهٔ موقت استفاده می‌کنند. آزمون‌های رابط با Node 24 بررسی شده‌اند. Node و npm فقط برای توسعه، آزمون و ساخت دوبارهٔ رابط لازم‌اند. خروجی ساخت با همان سرور Python ارائه می‌شود.

رابط از تم، توکن‌ها و کامپوننت‌های رسمی [Dig Design System](https://www.digdesign.ir/) استفاده می‌کند. تصمیم‌های طراحی در `AGENTS.md` و `DESIGN.md` ثبت شده‌اند. رنگ پیش‌فرض Dig، شعاع پیش‌فرض و تم تیرهٔ آبی انتخاب شده‌اند. فایل‌های رجیستری و نسخه‌های نصب‌شده در `ui/frontend/.dig/registry-lock.json` و `package-lock.json` ثبت می‌شوند.

فونت انتخاب‌شده IRANSansX است. فایل دارای مجوز این فونت هنوز در پروژه ارائه نشده؛ بنابراین `brand.css` آن را در اولویت قرار می‌دهد و تا زمان افزودن فایل‌ها، از وزیرمتن محلی با مجوز OFL به‌عنوان جایگزین استفاده می‌شود. برای فعال‌کردن فونت انتخاب‌شده، فایل‌های دارای مجوز را به دارایی‌های عمومی رابط اضافه و `@font-face` را فقط در `ui/frontend/src/app/brand.css` تعریف کنید. فونت به‌صورت جداگانه روی کامپوننت‌ها تنظیم نمی‌شود.

مرجع بررسی قالب فایل، [مشخصات PNG در W3C](https://www.w3.org/TR/png-3/) است.
